# Model registry

Generated by `python scripts/build_pipeline.py` (artifacts are derived from private data and are not committed):

- `registry.json` — ensemble version, weights, rules version, every artifact with SHA-256 and fingerprint, training/held-out days, per-model configs and status, evaluation summary.
- `feature_schema.json` — model input features per substation.
- `ensemble/<substation>/fold-<day>.joblib` — leave-one-day-out models (used to score that day); `full.joblib` — all-days model for future data.
- `isolation_forest/`, `autoencoder/`, `temporal_autoencoder/` — `metadata.json` (version, config, dataset, run id).
- `lstm_autoencoder/`, `supervised/` — `metadata.json` with status **not trained** and the reason.

Training code: `ml/pipeline/` (`model.py` Isolation Forest, `ensemble.py` autoencoders + combination, `rules.py`, `build.py`). Inference: `ml/pipeline/ensemble.py::EnsembleBundle.score` (used live by `backend/app/services/store.py`).
